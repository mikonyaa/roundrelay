# RoundRelay implementation and gates

1. Strict portable schema, independent hard validator, frozen round snapshots, pure commands.
2. Absolute-deadline timer, bounded future repair in a cancellable worker, atomic apply/undo.
3. Conductor, CSV/JSON preview, IndexedDB ownership/recovery, public-only projector, print routes.
4. Independent small-case oracle, real multi-tab rehearsal, renderer suspension, 60-person QA.
5. Offline consumer ZIP, recorded synthetic demo, notices, docs and publication audit (Gate A).
6. New public repository; exact push/main CI commit, CI ZIP, Pages, immutable release (Gate B).
7. Anonymous ZIP and actual Pages rehearsal.

Design: restrained editorial utility, DFII 14 (impact 4, fit 5, feasibility 5, performance 5, risk 5).
DM Sans body and IBM Plex Mono timer, locally bundled OFL fonts; green ink on warm white.
The round timeline and oversized timer are the visual anchors. No animation or remote assets.

Workspace isolation: all source, dependencies and tools in this new directory; ephemeral browsers
use temporary profiles. Never close unrelated browsers, alter other repositories, global config,
system date or sleep the workstation. Publication uses the existing verified GitHub identity.
